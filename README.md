# Joshua Hull

**Senior Software Engineer** · [joshua-hull.is-a.dev](https://joshua-hull.is-a.dev)

Hi, I'm Joshua. I've been building software professionally since 2015, and I've
called the Upstate of South Carolina home since high school.

My work spans the full stack — the systems and databases behind an application
as much as the interface someone actually clicks. A lot of it is internal
tooling, the cloud infrastructure it runs on, and getting systems that were
never designed to talk to each other to do exactly that.

Away from the keyboard I'm usually behind a camera or spending time with my
family.

## Selected work

These live in private repositories, so the write-ups are on my site rather than
here:

- **[Time Block](https://joshua-hull.is-a.dev/projects/time-block/)** — a
  local-first planner that auto-allocates your work week across projects, around
  the meetings you can't move.
- **[Strength MCP](https://joshua-hull.is-a.dev/projects/strength-mcp/)** — an
  MCP server for logging and reviewing strength training, backed by a single
  local DuckDB file.
